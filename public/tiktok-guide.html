Guía detallada — TikTok Business Messaging API

Cada valor / código tiene un botón Copiar. Reemplaza los marcadores APP_ID, APP_SECRET, AUTH_CODE por los tuyos.

⚠️ Paso 0 — Verifica la elegibilidad ANTES de empezar

La Business Messaging API solo cubre mensajes que llegan por TikTok Messaging Ads (el usuario toca “Mensaje” en tu anuncio) o por TikTok Shop. NO cubre los DM orgánicos a tu perfil (TikTok no expone esos por API, por privacidad).

  • ¿Tus leads empiezan desde un anuncio o Shop? → ✅ continúa.
  • ¿Te escriben directo al perfil (orgánico)? → ❌ esta API no aplica. Usa texto desde la app + la interfaz de GHL para archivos.

La revisión tarda días/semanas — no la inicies si tus DM son orgánicos. Los DM que recibe GHL funcionan porque GHL es socio oficial de mensajería de TikTok; ese acceso no se puede replicar como tercero.

Las dos plataformas de TikTok (no las confundas)

PlataformaPara qué¿Mensajería?
developers.tiktok.com
(TikTok for Developers)		Login Kit, publicar videos, datos de perfil. Apps de consumidor.❌ No
business-api.tiktok.com
(API for Business)		Anuncios, Marketing API y Business Messaging. Anunciantes.✅ Sí (gated)

Para mensajería usas API for Business. El SDK público es de anuncios; los endpoints de mensajería se entregan tras aprobar el producto Business Messaging.

Requisitos previos

  • ✅ Cuenta TikTok Business verificada (ya la tienes).
  • Perfil de empresa completo + documentos de registro del negocio.
  • Historial de inversión publicitaria ayuda (no siempre obligatorio).
  • URL de política de privacidad + redirect HTTPS público (ya tienes api.coaccrm.com).

1Registrarte como desarrollador

Inicia sesión con tu cuenta TikTok Business y regístrate en el portal:

Portal
https://business-api.tiktok.com/portal

2Crear la app

En My Apps → Create. Plataforma: Server-side / Web. Pega estos valores:

Nombre de la app
COAC CRM – TikTok Messaging
Descripción (específica — las vagas son la causa nº1 de rechazo)
COAC CRM is a customer-support inbox for our dental clinic. We integrate TikTok business messaging so our agents can receive messages from leads who contacted our business via TikTok ads / TikTok Shop and reply from a single CRM inbox. We only access messaging data for conversations the user initiated with our business, to provide timely customer service.
Redirect URI (OAuth callback)
https://api.coaccrm.com/oauth/tiktok/callback

3Solicitar el producto / scope Business Messaging

Agrega el producto Business Messaging API y solicita solo el/los scope(s) de mensajería. Pedir scopes de más retrasa o tumba la aprobación.

Referencia de scopes
https://developers.tiktok.com/doc/scopes-overview

4Enviar a revisión (días → semanas)

TikTok revisa manualmente. Causas comunes de rechazo: descripción vaga, scopes de más, falta de verificación del negocio, o caso de uso fuera de ads/Shop.

5Credenciales

Al aprobarse obtienes App ID y App Secret. Guárdalos seguros — me los pasarás.

6OAuth — obtener el access token (con código real)

6.1 — Enviar al usuario a autorizar

Abre esta URL en el navegador (reemplaza APP_ID y STATE). TikTok pedirá permiso y redirigirá a tu callback con ?auth_code=...:

URL de autorización
https://business-api.tiktok.com/portal/auth?app_id=APP_ID&state=STATE&redirect_uri=https%3A%2F%2Fapi.coaccrm.com%2Foauth%2Ftiktok%2Fcallback

6.2 — Intercambiar el auth_code por tokens

Tu servidor recibe auth_code en el callback y hace este POST:

curl — token exchange
curl -X POST 'https://business-api.tiktok.com/open_api/v1.3/oauth2/access_token/' \ -H 'Content-Type: application/json' \ -d '{ "app_id": "APP_ID", "secret": "APP_SECRET", "auth_code": "AUTH_CODE", "grant_type": "authorization_code" }'

Respuesta (forma): { "data": { "access_token": "...", "refresh_token": "...", "expires_in": ... } }. El access token de mensajería suele durar ~24 h; el refresh token ~1 año (refrescas el access token a diario). La forma exacta la confirma el Education Hub tras aprobar.

6.3 — Base URL y cómo se usa el token

Base API URL
https://business-api.tiktok.com/open_api/v1.3

El access_token se envía en la cabecera Access-Token (o como campo, según el endpoint).

7Enviar mensajes

  • Texto: envío directo al endpoint de mensajería (lo entrega el Education Hub tras la aprobación).
  • Archivos: primero subes el media a TikTok, luego envías un mensaje que referencia el media id.
  • Ventana de mensajería: solo puedes responder dentro de cierto periodo tras el contacto del usuario.
Education Hub (specs de envío)
https://business-api.tiktok.com/portal/bm-api/education-hub
SDK oficial (referencia de auth)
https://github.com/tiktok/tiktok-business-api-sdk

✅ Qué enviarme cuando esté aprobado

Para integrar el envío/recepción en la app necesito:

  • App ID + App Secret
  • El access token (o me dejas construir el callback OAuth para generarlo y refrescarlo solo)
  • Confirmación del scope de mensajería otorgado y el origen de los leads (ads / Shop)

Con eso: el agente envía texto/archivo → la app llama a la Business Messaging API → se entrega, y las respuestas vuelven al inbox.
